# MIDIassistant

一个轻量级、精准的 Rust 桌面 MIDI 钢琴卷帘窗可视化工具。

## 🎯 v0.1.1 功能
- 支持直接选择任意 `.mid` 文件加载（不再是硬编码路径）。
- 精准的 BPM 时间同步与物理播放引擎。
- 钢琴键盘 + 音高网格对齐，音符实时高亮响应。
- 底部进度条（支持拖拽）。
- 侧边栏实时显示 BPM、拍号、音符总数等信息。

## 🎨 强大的视觉自定义设置 (v0.1.2)
软件现在内置了 `⚙️ 视觉设置` 折叠面板，你可以实时调节以下参数：
- **背景 RGB**：使用 0.0 ~ 1.0 滑块微调底色，并配有实时预览色块。
- **键盘比例**：独立调节白键宽度、黑键宽度以及黑键高度。
- **音符与标注**：调整音符方块的视觉高度比例，以及音名文字（如 C4）的垂直微调偏移。
- **垂直音域滑动**：通过拖拽“基准音高”滑块，平滑滚动可见的音域范围。

> ❗ **钢琴键盘修复**：键盘绘制逻辑已彻底重写，严格遵循物理钢琴 **“七白键、五黑键”** 的排布，彻底修复了之前音符与白键错位的对齐问题。

## ⌨️ 控制方式
- `空格键`: 播放 / 暂停
- `R 键` : 重置到开头
- 点击左侧按钮 `打开 MIDI 文件` 即可载入。

## 🚀 编译与运行
`cargo run --release`
